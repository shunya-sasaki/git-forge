A fast, standalone CLI for Git forges such as GitHub, GitLab, and Gitea, written in Rust.

`git-forge` (`gf`) provides a single, consistent command-line interface across
different Git hosting platforms by communicating directly with their REST APIs.

- **Zero external CLI dependencies:** Calls GitHub, GitLab, and Gitea APIs directly
  without requiring `gh`, `glab`, or `tea`.
- **Auto-detection:** Automatically identifies the target forge and repository
  from your Git remote.
- **Streamlined local Git workflows:** Includes built-in helpers
  for `status`, `diff`, `commit`, and `worktree` management with clipboard (and OSC52) support.
